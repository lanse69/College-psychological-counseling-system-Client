# PsyClient - 心理咨询系统客户端

## 📱 简介
`PsyClient` 是高校心理咨询系统的用户终端。它采用 **Qt Quick (QML)** 构建现代化的用户界面，通过 TCP Socket 与服务端通信。

**注意**：本客户端**不直接连接数据库**，所有数据交互均通过 JSON 请求发送至服务端。

## ✨ 功能特性

### 👨‍🎓 学生端
- **医生浏览**: 查看心理医生信息、擅长领域及详细排班表。
- **在线预约**: 发起预约、查看历史咨询记录。
- **问卷系统**: 预约后填写心理问卷，支持在线提交。
- **预约管理**: 修改预约时间（需服务端校验冲突）、取消预约。

### 👩‍⚕️ 医生端
- **排班管理**: 可视化修改个人排班表（新增/取消/暂停时段）。
- **预约处理**: 查看预约学生详情及问卷结果；处理学生的改期申请。
- **报告撰写**: 填写咨询结果报告并归档。
- **消息通知**: 接收预约变更及学生改期申请的即时通知。

### 👮 管理员端
- **人员管理**: 增加、删除、修改学生和医生账户信息。
- **数据可视化**: 导出并查看统计图表（咨询人数趋势、热门咨询问题、常预约时间段等）。

## 📂 目录结构
PsyClient/

├── src/

│   ├── network/        # TCP Socket 客户端 & 数据包分发器

│   ├── controllers/    # C++ 逻辑控制层 (暴露给 QML 调用)

│   ├── models/         # QAbstractListModel 数据模型

│   └── main.cpp        # 程序入口

├── qml/

│   ├── views/          # 页面视图 (Student, Doctor, Admin 文件夹)

│   ├── components/     # 通用组件 (日历, 图表, 按钮)

│   └── Main.qml        # 主窗口

└── CMakeLists.txt      # 构建脚本

## 🛠️ 构建指南 (CMake)

### 前置要求
- Qt 6.x (Core, Gui, Qml, Quick, Network)
- C++ 编译器 (MSVC / GCC / Clang，支持 C++17)
- CMake (3.16+)

### 编译步骤
mkdir build && cd build

cmake ..

cmake --build .

### 运行
./PsyClient

### 连接服务器
在登录界面的设置或输入框中，确保目标 IP 和 端口 指向正在运行的 PsyServer。

## ⚠️ 注意事项
客户端 没有数据库驱动，所有数据均来自网络请求。

必须配合 PsyServer 才能完成登录和业务操作。
